# Selenium Browser Automation

## Overview
A Python-based browser automation project using Selenium WebDriver to automate repetitive tasks through web interfaces. The project explores automating email labelling in Gmail using browser interactions.

## Features
- Automates browser interactions using Selenium WebDriver.
- Demonstrates automation of repetitive email-labelling tasks.
- Uses Python to interact with web page elements.
- Reduces the need for repetitive manual browser operations.

## Technologies Used
- **Programming Language:** Python
- **Automation Framework:** Selenium WebDriver
- **Browser:** Google Chrome

## Prerequisites
- Python 3.x
- Google Chrome
- Selenium Python package

## Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/Sakshu-21/selenium-browser-automation.git
cd selenium-browser-automation
```

### 2. Install Dependencies
```bash
pip install selenium
```

### 3. Run the Script
```bash
python your_script_name.py
```

Replace `your_script_name.py` with the actual Python script filename in the repository.
